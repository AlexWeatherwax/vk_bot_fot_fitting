# Наборы

В активном каталоге семь наборов: «Алые капли леса», «Зимние ягоды»,
«Ледяное озеро», «Лесное волшебство», «Отголоски лета», «Первые лучи
солнца» и «Раннее утро».

Используются фронтальные предметные PNG `curated-*-front-tryon-v3.png`
из принятой папки `фото для калибровки/анфас-v3/assets/`. Для каждого
изделия в `manifest.json` есть отдельный компонент с якорем и масштабом.
Общая карточка набора использует PNG первого компонента.

В «Зимних ягодах» диадема и височные цепочки объединены в один прозрачный
PNG размером 936×900; центр крепится точкой `[0.5, 301/900]`.
Серьга с листом — отдельный компонент, зеркалящийся на второе ухо.
«Отголоски лета» содержат только серьги и колье.

«Ледяное озеро» содержит подготовленную пару разных серёг и браслет.
Это последовательная примерка по двум фотографиям: лицо, затем рука.
Остальные шесть наборов примеряются совместно на прямом фото лица и плеч.

Исходные фото и калибровки сохранены. Два уникальных старых PNG зимнего
набора перенесены в `scripts/catalog_import/work/curated_replaced_unique/`.
Происхождение файлов, SHA-256, старые и принятые параметры записаны в
`data/audit/curated-catalog-integration.json`.

Обновление каталога: `scripts/catalog_import/8_integrate_curated.py --apply`.
Исторический `prepare_winter_berries.py` сохраняет старую подготовку;
он не заменяет принятые фронтальные ассеты автоматически.

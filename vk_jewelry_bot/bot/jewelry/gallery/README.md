# Галерея украшений

`manifest.json` — активный каталог бота: **88 карточек**, включая **7 наборов**.
Все 88 моделей из локальной папки `Украшения ` (в имени есть конечный пробел)
доступны для выбора. PNG содержат прозрачный фон и отдельные изображения
изделий; полноразмерные слои, подогнанные под конкретное фото, в каталоге
не используются.

Рабочая галерея содержит 95 PNG; все они используются манифестом.
Изображения и калибровки редактируются через [админку автора](../../../jewelry_editor/README.md).
Изменение каталога подхватывается ботом без перезапуска. Не заменяйте эту папку
исходной копией при обновлении установленного сервиса.

Исторические инструменты массового импорта описаны в
[инструкции импорта](../../../scripts/catalog_import/README.md). Исходная коллекция,
архивы и отчёты импорта остаются локальными материалами и не входят в репозиторий.
Для повторного импорта их нужно предоставить отдельно. Старый `5_assemble.py`
сбрасывает калибровку и по умолчанию заблокирован.

## Формат карточки

```json
{
  "id": "earrings_star",
  "name": "Серьги Звезда",
  "category": "earrings",
  "image": "earrings_star.png",
  "anchor_scale": 1.0,
  "offset_x": 0.0,
  "offset_y": 0.0,
  "rotation_offset": 0.0,
  "overlay_anchor": [0.5, 0.03]
}
```

- `id` — устойчивый уникальный идентификатор; `name` — название для поиска.
- `category` — `earrings`, `pendant`, `ring`, `beads`, `diadem`, `hairpin`,
  `brooch`, `bracelet`, `kaffy` или `set`.
- `image` — путь PNG относительно этой папки.
- `anchor_scale` — множитель размера, рассчитанного алгоритмом примерки.
- `offset_x`, `offset_y` — подстройка в долях размера лица, плеч, пальца
  или запястья, соответствующего категории.
- `rotation_offset` — дополнительный поворот в градусах PIL.
- `overlay_anchor` — точка крепления **на самом PNG**, в долях его ширины
  и высоты с учётом обрезки и прозрачных полей. Если поле отсутствует,
  действует стандартная точка категории. Это не координаты на фото человека.

Для диадем точка крепления находится у центрального нижнего кончика.
Фронтальные диадемы имеют `anchor_scale: 1.3` и `offset_y: 0.2`.
У зимней диадемы височные цепочки включены в один предметный PNG;
его якорь `[0.5, 301/900]` удерживает центр диадемы на лбу.

## Дополнительные поля

- Серьги: `pair_image` — PNG содержит пару, которую алгоритм разделяет;
  `single_ear` — единственная серьга без зеркального повторения.
- Кулоны: `chain_color` — `curated_silver`, `curated_gold`, `curated_brass`,
  `curated_copper`, `curated_dark_silver` или `none`. Подготовленные
  фотоцепочки находятся в `bot/tryon/assets/chain_curated_*.png`.
  Старые ключи `silver` и `gold` также поддерживаются.
- Броши: `brooch_side`, сторона кадра `left` или `right`.
- Каффы: `kaffy_side`, анатомическая сторона `left` или `right`;
  `kaffy_anchor_y` — запасной вертикальный якорь при отсутствии
  `overlay_anchor`. У принятых каффов якорь задан отдельно для каждого PNG;
  у двух исправленных моделей используются последние ассеты v3.
- Заколки: `hairpin_style: bun` — поиск пучка и сокрытие стержня в волосах;
  `hairpin_head_fraction` — граница головки и стержня в координатах PNG.
  Автомат использует `hairpin_style: side` и `hairpin_side`.
  Исторический `updo` остаётся совместимым значением.

## Наборы

Карточка `category: set` содержит `components`; у каждого компонента свои
ID, категория, PNG и калибровка. Поле `image` карточки может ссылаться на
изображение первого компонента: для примерки используются все компоненты.

У шести наборов `tryon_mode: combined`: совместимые украшения накладываются
на одно прямое фото лица и плеч. В «Отголосках лета» находятся только
серьги и колье. «Ледяное озеро» имеет `tryon_mode: sequential`: сначала
примеряются разные серьги на лице, затем браслет на отдельном фото руки.

Каталог автоматически перечитывается после изменений манифеста. Если
новый файл повреждён, работающий бот сохраняет последнюю исправную версию
и записывает ошибку в журнал. Базовые точки посадки на фото определяет
штатный конвейер MediaPipe; параметры карточек уточняют посадку самого арта.

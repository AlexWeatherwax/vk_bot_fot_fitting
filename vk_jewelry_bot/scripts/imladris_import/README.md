# Импорт каталога из VK-группы (studio_imladris)

Перед шагом сборки (3) остановите бот и редактор; запускайте их снова после
проверки готовой галереи. Этот прежний импортёр заменяет файлы на месте.


Это прежний, дополнительный способ подготовки каталога. Текущая галерея
используется ботом напрямую; её основной источник — локальный архив
`assets/source_photos/` и [catalog_import](../catalog_import/README.md).

**Повторная сборка требует проверки.** Скрипт `3_assemble_into_catalog.py`
добавляет записи к существующему `manifest.json` без проверки уже загруженных ID,
копирует картинки поверх существующих и перезаписывает `NEEDS_REVIEW.md`.
Повторный запуск может создать дубли и затереть ручные изменения изображений
или документации. Выполняйте импорт в отдельной ветке, предварительно сохранив
текущую галерею коммитом, и проверьте diff перед использованием результата.
Входной `products.jsonl` нужно подготовить самостоятельно; в репозитории его нет.

Этот набор скриптов воспроизводит то, как в каталог бота были добавлены
58 реальных товаров из группы https://vk.ru/studio_imladris — на случай,
если студия добавит новые украшения и каталог нужно будет пополнить.

Сама выгрузка ссылок на фото с сайта ВК (шаг 0) делалась вручную через
браузер вместе с Claude — на страницах товаров ВК нет публичного API без
токена, а нужные фото в полном разрешении подгружаются JS-кодом страницы,
поэтому просто скачать HTML недостаточно. Дальше — шаги 1-3 полностью
автоматические и переиспользуемые.

## Шаг 0 (вручную/через Claude): собрать `products.jsonl`

Нужно получить список `{category, title, url}` — по одной строке JSON на
товар — и сохранить в `products.jsonl` рядом с этими скриптами. `url` —
это прямая ссылка на полноразмерное фото товара (на CDN `vkuserphoto.ru`,
с параметром `cs=<ширина>x0` на максимальном значении из `as=`, см. пример
ниже). Проще всего — попросить Claude (у которого есть доступ к браузеру)
снова открыть нужные разделы каталога и собрать эти ссылки, как это было
сделано в этот раз.

Пример строки:
```json
{"category": "earrings", "title": "Серьги \"прибой\"", "url": "https://sun9-24.vkuserphoto.ru/s/v1/ig2/....jpg?...&cs=2000x0"}
```
`category` — одна из: `earrings`, `pendant`, `ring`, `beads`, `diadem`.

## Установка зависимостей (отдельно от бота)

```bash
pip install -r scripts/imladris_import/requirements-import.txt
```

## Шаг 1 — скачать фото

```bash
python scripts/imladris_import/1_download.py
```
Скачивает все URL из `products.jsonl` в `scripts/imladris_import/raw/<категория>/`.

## Шаг 2 — убрать фон (rembg)

```bash
python scripts/imladris_import/2_remove_background.py
```
При первом запуске скачает модель u2net (~176 МБ) в `~/.u2net/`.
Результат — `scripts/imladris_import/cutout/<категория>/*.png` с прозрачным
фоном + автоматической подрезкой по границам предмета. Товары, у которых
вырезанная область подозрительно велика относительно всего кадра (похоже,
модель заодно оставила блюдце/вазу/подставку) — помечаются `FLAGGED` в выводе.

## Шаг 3 — добавить в каталог бота

```bash
python scripts/imladris_import/3_assemble_into_catalog.py
```
Копирует готовые PNG в `bot/jewelry/gallery/imladris/<категория>/` и
дописывает соответствующие записи в `bot/jewelry/gallery/manifest.json`
(существующие записи не удаляются, только дополняются). Список товаров,
которые стоит проверить/подрезать вручную, сохраняется в
`bot/jewelry/gallery/imladris/NEEDS_REVIEW.md`.

## Известное ограничение

Автоматическое удаление фона (rembg/u2net) — это универсальная модель
выделения "главного объекта", а не специализированная модель именно для
украшений. На фото, где украшение снято на выразительном реквизите
(блюдце, гранёный камень, ваза, манекен-подставка), модель иногда путает
"украшение" и "предмет, на котором оно эффектно разложено", и оставляет
часть фона непрозрачной. `NEEDS_REVIEW.md` перечисляет самые очевидные
такие случаи (по грубой эвристике — доле кадра, занятой непрозрачной
областью), но эвристика не идеальна: возможны и пропущенные случаи, и
ложные срабатывания (например, на широкой диадеме, которая и так занимает
почти весь кадр). Перед боевым использованием стоит один раз глазами
пролистать `bot/jewelry/gallery/imladris/` — при необходимости чуть
подрезать 1-2 карточки в Photopea/GIMP/Photoshop (обычно достаточно стереть
кистью остаток фона вокруг украшения).

# Галерея украшений

Здесь лежат сами картинки украшений (PNG, обязательно с прозрачным фоном / альфа-каналом)
и `manifest.json` — список украшений с привязкой к файлам.

При старте проекта в этой папке лежат **PNG-заглушки** (`earrings_moon.png` и т.п.),
сгенерированные скриптом `scripts/generate_placeholder_gallery.py` — они нужны только
чтобы сразу проверить, что вся цепочка (поиск -> запрос фото -> примерка -> отправка
результата) работает. Их можно удалить в любой момент — на боевой каталог не влияют.

## Каталог studio_imladris

В подпапке `imladris/` — настоящие товары студии
[studio_imladris](https://vk.ru/studio_imladris): серьги, кольца, кулоны и колье,
диадемы, заколки, броши, браслеты. Записи для них уже есть в `manifest.json`.

Картинки собраны из локального архива фотографий студии (папка `Украшения/`
рядом с папкой бота): у каждого товара там несколько ракурсов, из них
выбирается самый пригодный для примерки, и с него снимается фон. Как это
сделано и как повторить для новых товаров — см.
[scripts/catalog_import/README.md](../../../scripts/catalog_import/README.md).

Что стоит доправить руками — в [imladris/NEEDS_REVIEW.md](imladris/NEEDS_REVIEW.md).

В `imladris/_ready_no_category/` лежат готовые PNG каффов и наборов: у бота
пока нет подходящей точки крепления (кафф сидит на ушной раковине, а не на
мочке; набор — это несколько разных изделий), поэтому записей в `manifest.json`
у них нет. Появится категория — файлы уже готовы.

## Как добавить своё украшение

1. Подготовьте фото украшения:
   - вырежьте украшение из фона (например, в Photoshop/GIMP/remove.bg) так, чтобы
     фон стал прозрачным — итоговый файл должен быть **PNG с альфа-каналом**;
   - украшение должно быть развёрнуто анфас/фронтально, как оно обычно надевается;
   - для серёг годится и одна серьга, и пара в кадре — см. `pair_image` ниже;
   - для кулона на картинке не должно быть длинной цепочки: цепочку на шее бот
     рисует сам (см. `chain_color`), достаточно оставить сам подвес;
   - для кольца/диадемы/бус/заколки/броши/браслета — как есть, в естественной
     ориентации.
2. Положите файл в эту папку, например `earrings_star.png`.
3. Добавьте запись в `manifest.json`:

```json
{
  "id": "earrings_star",
  "name": "Серьги Звезда",
  "category": "earrings",
  "image": "earrings_star.png",
  "anchor_scale": 1.0,
  "offset_x": 0.0,
  "offset_y": 0.0,
  "rotation_offset": 0.0
}
```

Где:
- `id` — уникальный технический идентификатор (латиницей, без пробелов);
- `name` — то, что пользователь будет вводить в чате (можно с любыми пробелами/регистром —
  поиск нечувствителен к регистру и допускает неточный ввод);
- `category` — одна из: `earrings`, `pendant`, `ring`, `beads`, `diadem`,
  `hairpin` (заколка/шпилька), `brooch` (брошь), `bracelet` (браслет);
- `anchor_scale` — множитель размера именно для этой картинки (1.0 — как рассчитано
  автоматически; 1.2 — на 20% крупнее и т.д.). Нужен, если на конкретной фотографии
  украшение получается визуально мельче/крупнее, чем должно;
- `offset_x`, `offset_y` — точная подстройка положения (в долях характерного размера:
  ширины лица для серёг/диадемы/заколки, ширины плеч для кулона/бус/броши,
  ширины ладони для кольца, ширины запястья для браслета);
- `rotation_offset` — доп. поворот в градусах, если украшение на изображении и так
  повёрнуто (например, кольцо сфотографировано не строго анфас).

Дополнительные поля по категориям:
- `pair_image` (только `earrings`) — на картинке обе серьги пары. Бот сам
  разберёт её на две детали и посадит каждую на своё ухо. Если пара на
  картинке слиплась в одно пятно, бот вставит картинку целиком между ушами.
  Без этого поля картинка считается одной серьгой и отражается на второе ухо;
- `single_ear` (только `earrings`, при `pair_image: false`) — несимметричная
  моно-серьга: надевается только на одно ухо, зеркалить не надо;
- `chain_color` (только `pendant`) — каким металлом подрисовать цепочку на шее:
  `"silver"` (по умолчанию), `"gold"` или `"none"`;
- `brooch_side` (только `brooch`) — на какой стороне кадра носить брошь,
  `"left"` (по умолчанию) или `"right"`.

4. Перезапустите бота (или вызовите `catalog.reload()`, если меняете каталог "на лету").

Никакой отдельной калибровки координат вручную делать не нужно — базовое положение
(за ухом, на шее, на пальце, на лбу, на макушке, под ключицей, на запястье) бот
определяет автоматически по фото пользователя через mediapipe (лицо/поза/руки).
Поля выше — это только тонкая подстройка под конкретную картинку украшения.

Посмотреть, как села конкретная запись, можно на калибровочных фото:

```bash
.venv-mp/bin/python scripts/catalog_import/7_calibrate_preview.py --id imladris_ring_koltso-svet-luny
```

# Статус ручной подрезки 22 помеченных фото

После автоматического удаления фона (rembg) 22 из 58 фото были помечены как
подозрительные (реквизит, вероятно, остался). Дальше их разобрали вручную:
для части реквизит физически отделён от украшения (стенд сверху, отражение
снизу) — там подрезка кадром полностью убрала лишнее. Для другой части
реквизит (кружка, банка, стеклянное блюдце, манекен-бюст, медная
проволочная «ветка»-подставка) сфотографирован **впритык к украшению по
всему кадру** — модель удаления фона считает его частью того же объекта, и
никакая обрезка кадра тут в принципе не поможет: нужна точечная закраска
реквизита вручную (кистью в Photopea/GIMP/Photoshop), которую нельзя
корректно сделать координатами наугад — для этого нужен человек с мышкой.

Для этой группы (10 файлов) я обрезал кадр максимально плотно вокруг самого
украшения — это уменьшает абсолютный размер лишнего фона при масштабировании
под фото клиента, но не убирает его: реквизит той же текстуры/яркости, что и
часть самого украшения (серебро кольца ≈ серебро блюдца, тёплые тона кружки ≈
тёплые тона бусин), поэтому ни один автоматический критерий (цвет, резкость,
контур) не отделяет одно от другого надёжно — я пробовал три разных подхода
(обрезка кадром, цветовой порог, порог резкости/боке) и после проверки на
реальных примерах ни один не сработал для этой группы файлов.

# Имладрис: мастерская эльфийских украшений

Интерфейс автора связан с каталогом ВК-бота. Позволяет добавлять украшения
на прозрачном фоне, подгонять их на референсе, изменять существующие позиции
и удалять их из каталога.

## Работа автора

1. Нажмите **Новое украшение**, укажите название и тип.
2. Загрузите PNG или WebP с прозрачным фоном. Пустые края можно обрезать
   при загрузке, до начала подгонки.
3. Выберите подходящий референс: лицо в фас, ухо, кисть, запястье или пучок.
   Можно загрузить своё фото.
4. Перетащите само украшение на фото. Углы рамки меняют размер, круглая
   метка над рамкой — поворот. Изображение движется сразу; после отпускания
   сервер уточняет примерку тем же алгоритмом, который использует бот.
5. Нажмите **Добавить в каталог** или **Сохранить изменения**. Положение,
   масштаб и угол автоматически переводятся в параметры каталога.

Размер и угол также меняются ползунками или числовыми полями. Для точного
перемещения выделите украшение и используйте стрелки; Shift увеличивает шаг.
Клавиши + / − меняют размер, [ / ] — поворот. Есть отмена последнего действия,
сброс подгонки и скрытие меток. Дополнительные параметры категории находятся
в разделе **Точные настройки**.

Слева — каталог с поиском и фильтром. Нажмите позицию, чтобы открыть и изменить
название, тип, изображение или посадку. Совпадающее название не перезаписывает
другой товар. Переход из несохранённой карточки требует выбора автора.

Кнопка **Удалить из каталога** запрашивает подтверждение с названием позиции.
Перед сохранением и удалением создаётся резервная копия manifest. Исходные PNG
сохраняются, чтобы позицию можно было восстановить.

Готовые наборы также видны в каталоге. В обзоре можно изменить название набора.
Выберите часть комплекта в списке **Украшение набора**, чтобы заменить её
изображение, изменить тип или подогнать её на фото. Сохранение обновляет только
эту часть; настройки остальных изделий, ID и режим примерки набора сохраняются.
Несовместимый ракурс или повтор категории отклоняются. Набор можно удалить
целиком с подтверждением; части не превращаются в самостоятельные позиции.

## Запуск

Редактор работает отдельным процессом с одним worker. Нужны зависимости бота,
локальные модели из bot/tryon/models и зависимости редактора:

    cd /путь/к/vk_jewelry_bot
    source .venv/bin/activate
    python -m pip install -r jewelry_editor/requirements.txt
    export EDITOR_USER=author
    read -s -p 'Пароль редактора: ' EDITOR_PASSWORD; echo
    export EDITOR_PASSWORD
    python -m uvicorn jewelry_editor.app:app --host 127.0.0.1 --port 8765 --workers 1

Откройте http://127.0.0.1:8765/. Браузер попросит имя пользователя и пароль.
Пароль должен содержать не менее 16 символов. Не сохраняйте его в Git или URL.

HTML-файл можно открыть отдельно для просмотра оформления. В этом режиме
каталог и сохранение отключены; для работы автора нужен адрес запущенного сервера.

Для удалённого Linux-сервера используйте общую
[инструкцию развёртывания](../deploy/README.md) и службу `imladris-editor.service`.
Для постоянной работы одного владельца с Windows без домена подготовлен
клиент `windows/`: установщик создаёт ярлык, который открывает админку через
защищённый SSH-туннель. Каталог и обработка остаются на сервере.
Настройка ограниченного доступа и передача описаны в
[deploy/windows-owner.md](deploy/windows-owner.md), действия владельца — в
[windows/README.md](windows/README.md).

Для ручного подключения можно открыть SSH-туннель:

    ssh -L 8765:127.0.0.1:8765 пользователь@сервер

Если редактор публикуется как обычный сайт, используйте HTTPS; пример прокси —
`deploy/nginx.conf`. Публиковать Basic-аутентификацию через открытый HTTP нельзя.

На macOS для нативной примерки нужен совместимый MediaPipe и доступ к графическому
контексту ОС, даже если модель настроена на CPU. Каталог и интерфейс открываются
без инициализации моделей; модели загружаются при первом предпросмотре.
Рекомендуемая серверная среда проекта — Linux / Python 3.11.

## Каталог и параметры

По умолчанию используется bot/jewelry/gallery/manifest.json. Бот проверяет
изменение каталога перед поиском, показом и обработкой выбранной позиции:
успешные изменения редактора не требуют перезапуска бота.

Сохраняются anchor_scale, offset_x, offset_y, rotation_offset, overlay_anchor,
настройки пары серёг и поля конкретной категории. Это калибровка относительно
опорных точек тела, а не абсолютные пиксели одного фото. У пары серёг общие
размер и угол; направление смещения учитывает сторону уха. Цепочка кулона
следует за подвесом, сохраняя собственные размер и угол. Для шпилек итоговый
серверный предпросмотр учитывает перекрытие волосами.

Обновление сохраняет ID и дополнительные поля позиции. Новая версия изображения
получает уникальное имя в custom/; исходное изображение не перезаписывается.
JSON заменяется атомарно под блокировкой .editor.lock. Устаревшее сохранение
или удаление получает конфликт версии. При конфликте откройте позицию заново:
обновление списка само по себе не меняет версию открытой карточки.

Копии находятся в .editor-backups/, черновики — в .editor-staging/.
Черновики живут час с последнего использования; один процесс хранит до 80.
Резервируйте gallery целиком. Не запускайте несколько редакторов одновременно
и не публикуйте gallery как общедоступную статическую папку.

## Изолированная проверка

Для проверок без изменения рабочего каталога задайте EDITOR_GALLERY — путь
к копии gallery с manifest.json и изображениями. Сохранение и удаление будут
работать только с этой копией. Для предпросмотра сохраняются общие локальные
модели и фотографии-референсы проекта.

    export EDITOR_GALLERY=/путь/к/копии/gallery
    python -m pytest tests/test_jewelry_editor.py -q
    node tests/test_editor_transforms.cjs

API-тестам дополнительно нужны pytest и httpx. Они используют временную
галерею и заменяют только нативный детектор; операции записи, чтения, проверки
версий, авторизации и удаления выполняются настоящими обработчиками.

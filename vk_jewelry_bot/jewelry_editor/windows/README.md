# Мастерская Имладриса на Windows

Админка работает на сервере. На вашем компьютере ярлык открывает защищённое
подключение и запускает браузер. Покупать домен и устанавливать Python не нужно.

## Первоначальная настройка

Эти действия выполняются один раз вместе со специалистом, который устанавливает
сервис. Поддерживаются Windows 10 (1809 и новее) и Windows 11.

1. Нажмите правой кнопкой по ZIP-архиву и выберите «Извлечь всё». Откройте
   распакованную папку Imladris и запустите `Install.cmd` двойным щелчком из
   своей учётной записи Windows. Файл `Install.ps1` открывать не нужно.
   Если расширения файлов скрыты, включите их отображение в Проводнике
   и выберите именно `.cmd`.
2. Если потребуется компонент OpenSSH Client, специалист поможет включить его
   в настройках Windows и повторит установку.
3. Первый запуск создаст ваш ключ подключения. Передайте специалисту только
   публичный ключ `owner_ed25519.pub`, который покажет установщик.
4. После настройки сервера специалист передаст папку с заполненными настройками.
   Снова откройте `Install.cmd` на том же компьютере. Уже созданный ключ сохранится.
5. Откройте ярлык **Мастерская Имладриса** на рабочем столе. Если Windows запрещает
   сохранять ярлык на рабочий стол, ищите **Imladris** в меню «Пуск» или откройте
   `Launch.cmd` из распакованной папки. Вместе со специалистом проверьте,
   что открывается ваш каталог и сохраняются изменения.

До заполнения настроек сервера и проверки на вашем компьютере установка ещё
не завершена. Логин и пароль для входа в админку специалист передаст отдельно.

## Обычная работа

1. Дважды нажмите **Мастерская Имладриса** на рабочем столе, **Imladris** в меню
   «Пуск» или `Launch.cmd` в распакованной папке.
2. Дождитесь подключения. Админка откроется в браузере.
3. Введите логин и пароль, если браузер их запросит.
4. Работайте с каталогом. Чтобы сохранить подгонку, нажмите кнопку сохранения
   в самой админке.

Окно подключения можно свернуть. Пока вы редактируете украшения, оставьте его
работающим. После окончания работы закройте его кнопкой выхода.
Бот продолжит работать на сервере, даже когда вы выключите компьютер.

## Если ярлык не появился или прежняя установка завершилась ошибкой

Распакуйте новый комплект целиком и снова откройте `Install.cmd` из той же
учётной записи Windows. Установщик сохранит уже созданный ключ. Ошибка записи
ярлыка на рабочий стол больше не прерывает установку; для запуска всегда есть
`Launch.cmd` в распакованной папке.

Чтобы снова увидеть публичный ключ, дважды нажмите `Show-Key.cmd`. Он откроет
только файл `owner_ed25519.pub`. Если этот ключ уже добавлен на сервер,
повторно передавать его не требуется — можно открыть `Launch.cmd`.

## Если страница не открылась

Проверьте интернет и посмотрите сообщение в окне подключения. При временном
обрыве программа повторяет попытку подключения. После восстановления связи
можно снова открыть страницу кнопкой в этом окне. Несохранённую карточку
после перезагрузки сервера может потребоваться открыть и подогнать заново.

Если программа сообщает об изменении ключа сервера, сначала нужно проверить
сервер через кабинет INVS. Такой запрос не следует обходить отключением
проверки. Оплата и состояние VPS также проверяются в вашем кабинете INVS.

Настройки установлены в `%LOCALAPPDATA%\Imladris`. Файл `owner_ed25519` — ваш
закрытый ключ. Храните его резервную копию у себя и не пересылайте вместе с
сообщениями об ошибках. После замены компьютера настройку доступа нужно
восстановить из своей копии либо создать новый ключ через кабинет хостинга.

Установка не требует открытия терминала и не меняет общую политику выполнения
PowerShell. Если на рабочем компьютере действуют ограничения организации,
первую установку согласуйте с её администратором.

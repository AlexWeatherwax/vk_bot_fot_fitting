# VK-бот «Примерочная украшений»

Пользователь выбирает украшение по названию, получает инструкцию к фотографии
и присылает фото. Бот определяет ориентиры через MediaPipe, накладывает
прозрачный PNG через Pillow/OpenCV и отправляет результат в VK.

Поддерживаются серьги, кулоны, кольца, колье, диадемы, заколки, броши,
браслеты и каффы. Примерка использует приближённую геометрию по ключевым
точкам; качество посадки зависит от ракурса фото и настроек конкретного товара.

[Карта всего репозитория](../README.md).

## Установка и конфигурация

Используйте Python 3.11. Все команды ниже выполняются из `vk_jewelry_bot/`.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

На Linux для OpenCV и MediaPipe могут потребоваться системные библиотеки.
В Debian/Ubuntu:

```bash
sudo apt-get install libgl1 libgles2 libglib2.0-0
```

Заполните `.env`:

| Переменная | Значение |
|---|---|
| `VK_TOKEN` | Токен сообщества VK |
| `VK_GROUP_ID` | Числовой ID сообщества без минуса |
| `LOG_LEVEL` | Уровень логирования, по умолчанию `INFO` |

У сообщества должны быть включены сообщения и настроен доступ к Bots Long Poll.
Настройки читаются из `.env` в папке приложения; переменные окружения сервера
имеют приоритет. В Git хранится только пустой пример `.env.example`.

```bash
python run.py
```

Бот сам подключается к VK через Long Poll. HTTP-сервер для приёма сообщений
и запуск «Ларца» не требуются. Фотографии обрабатываются в памяти.

## Проверка в диалоге VK

1. Напишите сообществу `начать`.
2. Запросите `каталог`.
3. Отправьте название из текущего списка, например `Серьги Ягодные`.
4. Пришлите фото в рекомендованном ракурсе.
5. Проверьте полученный результат. Для выхода из ожидания фото напишите `отмена`.

Для запуска достаточно готовой галереи и трёх `.task`-моделей, уже находящихся
в `bot/`. Исходный фотоархив из `../assets/` используется при подготовке
новых товаров.

## Устройство приложения

| Модуль | Ответственность |
|---|---|
| `run.py`, `bot/app.py` | Запуск и регистрация обработчиков |
| `bot/config.py` | Настройки окружения |
| `bot/handlers/`, `bot/states.py` | Команды, выбор украшения и ожидание фото |
| `bot/vk_media.py` | Скачивание фото из VK и загрузка результата |
| `bot/jewelry/` | Модель украшения, чтение каталога, поиск |
| `bot/tryon/` | Ориентиры лица/плеч/руки и композиция изображения |

Обработчики регистрируются в порядке: ожидание фото → команды → свободный
поиск. Выбранный `item_id` хранится в состоянии диалога.
Перед поиском, показом каталога и примеркой проверяется изменение
`manifest.json`, поэтому новые сохранения редактора видны без перезапуска бота.

## Работа с каталогом

- [Редактор](jewelry_editor/README.md): добавление прозрачного PNG,
  предпросмотр и настройка масштаба, смещения, угла и стороны.
- [Галерея](bot/jewelry/gallery/README.md): формат `manifest.json`
  и параметры категорий.
- [Локальный импорт](scripts/catalog_import/README.md): подготовка
  фотографий из `../assets/source_photos/`.
- [Прежний импорт из VK](scripts/imladris_import/README.md):
  дополнительный способ для отдельных случаев.

Галерея содержит готовые рабочие изображения и ручную калибровку.
Шаг массовой сборки может сбрасывать параметры заменяемых товаров;
сохраните текущую галерею перед осознанной пересборкой. Перед массовой
сборкой остановите бот и редактор, затем запустите после её завершения.
Редактор и импортёр запускаются отдельно от процесса бота.

## Проверки без подключения к VK

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Проверяются поиск и перечитывание каталога, настройки, наличие и читаемость
его изображений, математика наложения и обработка фотографии без распознанных
ориентиров во всех категориях на настоящем MediaPipe.
Эти проверки не отправляют сообщения и фотографии в VK.

Для быстрых проверок каталога и конфигурации доступны тесты стандартной библиотеки:

```bash
python -m unittest tests.test_catalog tests.test_config -v
```

Основные зависимости находятся в `requirements.txt`, тестовые — в
`requirements-dev.txt`. Дополнительные зависимости редактора и импортёров
описаны в их инструкциях. Устанавливайте один пакет, предоставляющий `cv2`:
проект использует `opencv-contrib-python`, от которого также зависит MediaPipe.

## Запуск через Docker

Из `vk_jewelry_bot/` с заполненным `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

Образ содержит код бота, галерею и модели. `.dockerignore` исключает секреты,
временные данные, черновики редактора и вспомогательные инструменты.
Каталог `bot/jewelry/gallery/` подключён как том, чтобы видеть изменения
редактора. После изменения кода пересоберите образ той же командой.

## Запуск через systemd

Скопируйте папку приложения в `/opt/vk_jewelry_bot`, создайте там
`.venv`, установите зависимости и заполните `.env`.
В [systemd/vk-jewelry-bot.service](systemd/vk-jewelry-bot.service)
проверьте пользователя `botuser` и пути под вашу установку.

```bash
sudo cp systemd/vk-jewelry-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now vk-jewelry-bot
sudo systemctl status vk-jewelry-bot
journalctl -u vk-jewelry-bot -f
```

## Если запуск или примерка не удаётся

- Ошибка `VK_TOKEN` / `VK_GROUP_ID`: заполните `.env` в папке приложения.
- Ошибка `libGL.so.1` или `libGLESv2.so.2` на Linux: установите системные
  библиотеки из раздела установки.
- Не найдены модели: проверьте все три файла в `bot/tryon/models/`.
- Каталог загружается, но бот не отвечает: проверьте токен, настройки сообщений
  сообщества и вывод процесса.
- Не найдены лицо, рука или плечи: используйте подсказку бота к выбранной
  категории и более чёткую фотографию в нужном ракурсе.
- Для корректировки размера и положения используйте редактор. Изменение
  исходного алгоритма примерки не требуется для настройки отдельного товара.

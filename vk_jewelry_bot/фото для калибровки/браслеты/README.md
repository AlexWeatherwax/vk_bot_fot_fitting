# Слои браслетов

Четыре PNG с прозрачностью подготовлены по нескольким исходным фотографиям
каждого браслета. Это генеративная реконструкция; мелкие детали плетения
могут отличаться от исходных украшений.

Файлы имеют размер 1122×1402 и накладываются без смещения на
`../1000013934.jpg` (или идентичный `../1000013933.jpg`). Видна только
передняя часть браслета, задняя часть скрыта запястьем.

Для программы используются обрезанные версии в
`../../bot/jewelry/gallery/imladris/bracelet/` и их копии в
`../../scripts/catalog_import/work/cutout/bracelet/`. Имена файлов и ID
каталога сохранены. Ширина обрезанного изображения — 290 пикселей;
на референсе его левый верхний угол находится в точке (390, 1000).
Для других фотографий положение и масштаб определяет программа примерки.

Повторный запуск шага 4 импорта создаёт вырезы заново из исходных фотографий
и может перезаписать подготовленные браслеты.

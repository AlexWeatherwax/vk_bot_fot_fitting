# Диадемы для примерки анфас

Три фронтальные модели созданы по нескольким фотографиям каждого изделия.
Прозрачные PNG содержат переднюю часть диадемы и видимые участки у висков.
Манекен, фон и скрытая задняя часть обруча отсутствуют; просветы узора прозрачные.
Это генеративная реконструкция: мелкие детали проволоки, камней и бусин могут
отличаться от оригинала. Исходные фото сохранены.

| Диадема | Полноразмерный прозрачный слой |
|---|---|
| Ранняя осень | `rannyaya-osen.png` |
| Течение | `techenie.png` |
| Зимние ягоды | `zimnie-yagody.png` |

Слои 1122×1402 накладываются без смещения на `../1000013928.jpg`.
Варианты 1000013929–1000013932 содержат тот же синтетический портрет анфас.
Ширина украшения на референсе — 490 px, горизонтальный центр — 555 px.
Точка крепления (50% ширины, 90% высоты слоя украшения) находится в (555, 290).
Посадка выбрана вручную по верхней части лба и вискам, без наклона.

Каталожные PNG шириной 900 px находятся в
`../../bot/jewelry/gallery/imladris/diadem/`; одинаковые копии — в
`../../scripts/catalog_import/work/cutout/diadem/`.
Имена файлов, ID и названия записей сохранены. У «Зимних ягод» подготовлена
сама диадема, без длинных боковых серёг, как и в прежнем каталожном ассете.

В `manifest.json` для трёх диадем задан `offset_y: 0.20`: нижняя точка узора
опускается от линии волос на верхнюю часть лба. Масштаб и угол по-прежнему
определяет существующая программа, anchor_scale остаётся 1.
Предварительная очистка слабого альфа-фона использует текущий порог программы
`ALPHA_CLEAN_THRESHOLD = 160`; сохранившийся альфа-канал не заменяется сплошной маской.

Проверены прозрачность, размеры, идентичность копий и ручное наложение анфас.
Автоматическая посадка MediaPipe в этом окружении не проверена: загрузка
FaceLandmarker остановилась из-за отсутствия libGLESv2.so.2. Настройки смещения
нужно дополнительно проверить в рабочем окружении бота на разных лицах.

Повторный запуск импорта может перезаписать PNG и настройки manifest.json.
Необходимо сохранить эти изображения и offset_y при пересборке каталога.

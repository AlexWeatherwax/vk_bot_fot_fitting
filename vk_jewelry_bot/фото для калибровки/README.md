# Синтетические фото для калибровки

В этой папке находятся три сгенерированных кадра вымышленной взрослой модели:
анфас, три четверти и поднятая кисть тыльной стороной к камере. Они заменяют
личные фотографии и служат для тестовой примерки украшений и подстройки их
положения и масштаба.

## Имена файлов

Старые имена сохранены для совместимости с таблицами `PHOTO_FOR` в
`scripts/catalog_import/7_calibrate_preview.py` и `SETUP` в
`scripts/catalog_import/8_tryon_sheets.py`.

| Кадр | Файлы | Назначение |
|---|---|---|
| Анфас, видны макушка, шея, плечи и верх груди | `1000013928.jpg`, `1000013929.jpg`, `1000013930.jpg`, `1000013931.jpg`, `1000013932.jpg` | Серьги, диадемы, заколки, кулоны, бусы и броши |
| Кисть тыльной стороной, видны пальцы и запястье | `1000013933.jpg`, `1000013934.jpg` | Кольца и браслеты |
| Три четверти, ухо открыто | `1000013935_profil_ukho_kaffy.jpg` | Каффы |

Пять файлов анфас содержат один и тот же кадр; два файла кисти — один и тот
же кадр кисти. Эти копии сохраняют существующие пути в скриптах. Кадр в три
четверти также используется как фото по умолчанию в
`jewelry_editor/examples/model.jpg`.

## Повторная генерация листов примерки

Старые результаты в `scripts/catalog_import/work/calibrate/`,
`scripts/catalog_import/work/tryon_sheets/` и старый PDF
`scripts/catalog_import/Задание на пересъёмку.pdf` удалены, поскольку
содержали примерку на личных фотографиях.

Шаги 7, 8 и 8b позволяют создать новые листы и PDF на синтетических кадрах.
Запускайте их из корня `vk_jewelry_bot` в рабочем окружении проекта с
необходимыми зависимостями и шрифтами:

```bash
python scripts/catalog_import/7_calibrate_preview.py
python scripts/catalog_import/8_tryon_sheets.py
python scripts/catalog_import/8b_tryon_pdf.py
```

Новые рабочие результаты в указанных папках исключены из Git через
`.gitignore`.

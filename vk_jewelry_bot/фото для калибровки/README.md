# Синтетические референсы

Сгенерированные изображения вымышленной взрослой модели используются в
редакторе и в изолированных проверках примерки. Личные фотографии покупателей
в этот комплект не входят.

| Файл | Назначение |
|---|---|
| `анфас-v3/reference-front.jpg` | Лицо в фас: серьги и диадемы |
| `1000013935_profil_ukho_kaffy.jpg` | Три четверти, открытое ухо: каффы |
| `1000013933.jpg` | Кисть: кольца |
| `1000013934.jpg` | Кисть: браслеты |
| `заколки/reference-updo.png` | Пучок: шпильки |
| `кулоны/reference.jpg` | Шея и плечи: кулоны |
| `броши/reference-blouse.png` | Плечи и одежда: броши |

Два файла кисти содержат один кадр и сохраняют имена, используемые редактором.
Референсы лица и кулонов также совпадают; они оставлены по именам категорий.
Эти копии не считаются независимыми тестовыми фотографиями.

Старые ZIP-архивы, промежуточные PNG, контактные листы и отчёты исключены
из Git. Скрипты калибровки сохраняют новые результаты в локальные рабочие
каталоги, также исключённые из Git.

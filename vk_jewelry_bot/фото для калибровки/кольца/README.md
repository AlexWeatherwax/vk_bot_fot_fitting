# Слои колец для примерки

Пять колец восстановлены по исходным фотографиям в PNG с настоящим альфа-каналом.
Это генеративная реконструкция: мелкие детали оправы и текстура камней могут
отличаться от оригинальных украшений. Исходные фотографии сохранены.

## Файлы

| Украшение | Прозрачный слой |
|---|---|
| Лазурные воды | `lazurnye-vody.png` |
| Парад планет | `parad-planet.png` |
| Пески времени | `peski-vremeni.png` |
| Свет луны | `svet-luny.png` |
| Особенное | `osobennoe.png` |

Полноразмерные слои 1122×1402 накладываются без смещения на `../1000013934.jpg`
(или идентичный `../1000013933.jpg`). Центр кольца (446, 485), ширина до поворота
90 px, поворот на 4° против часовой стрелки. Эти параметры подобраны вручную
для безымянного пальца референса.

Для программы подготовлены обрезанные PNG шириной 480 px:
`../../bot/jewelry/gallery/imladris/ring/` и одинаковые копии в
`../../scripts/catalog_import/work/cutout/ring/`.
Имена файлов и ID каталога сохранены. Скрытая за пальцем задняя часть дужки
отсутствует. В каталожных изображениях верх украшения направлен к кончику пальца.

В `manifest.json` для этих пяти записей установлен `rotation_offset: 180`:
он компенсирует разворот, который текущая функция `get_ring_anchor` возвращает
для пальца, направленного вверх. Масштаб и положение на других руках определяет
существующий код примерки. Проверены альфа-канал, ссылки каталога и наложение
на референс; распознавание руки через MediaPipe здесь не запускалось.

Повторный запуск шага 4 импорта может перезаписать эти PNG исходными вырезами;
при пересборке каталога необходимо сохранить и `rotation_offset`.

# Исходные материалы

Здесь собраны данные для подготовки и проверки каталога. Бот использует готовые
PNG из `vk_jewelry_bot/bot/jewelry/gallery/`; для обычного запуска эти архивы
не требуются.

| Папка | Назначение |
|---|---|
| `source_photos/` | исходные фотографии украшений по разделам и товарам; прежняя папка `Украшения ` |
| `calibration_photos/` | пробные фото людей для проверки посадки украшений; прежняя папка `vk_jewelry_bot/фото для калибровки/` |
| `source_archive/kaffy/` | девять прежних фото каффов, сохранённых после пересъёмки; ранее находились внутри временной `work/` |

Внутренние имена файлов исходного архива сохранены. Скрипты импорта восстанавливают
испорченную кодировку названий в памяти через `common.demojibake()`.

Для внешнего архива задайте переменную окружения `JEWELRY_SOURCE_DIR`.
Порядок подготовки изображений и ручные настройки описаны в
[инструкции импорта](../vk_jewelry_bot/scripts/catalog_import/README.md).

Результаты обработки, резервные копии галереи и отчёты создаются локально в
`vk_jewelry_bot/scripts/catalog_import/work/` и исключены из Git. Постоянные
иллюстрации сравнения ракурсов кольца хранятся отдельно в
`vk_jewelry_bot/scripts/catalog_import/examples/`.

# Дополнительные инструменты

| Инструмент | Назначение | Связь с VK-ботом |
|---|---|---|
| [Ларец](larets-server/README.md) | Отдельный веб-каталог на Node.js: фотографии, названия, категории, удаление товаров | Хранит собственный каталог в `larets-server/data/`; синхронизации с ботом нет |
| [Редактор украшений](../vk_jewelry_bot/jewelry_editor/README.md) | Загрузка прозрачных изображений и калибровка примерки | Работает с каталогом и алгоритмом бота; находится рядом с `bot/` в `vk_jewelry_bot/` |
| [Импорт каталога](../vk_jewelry_bot/scripts/catalog_import/README.md) | Подготовка изображений из исходных фотографий | Собирает рабочую галерею бота |

Для запуска VK-бота Node.js и «Ларец» не требуются. Команды запуска бота находятся
в [его README](../vk_jewelry_bot/README.md).

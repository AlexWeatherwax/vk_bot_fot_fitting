# Имладрис: мастерская эльфийских украшений

Виртуальная примерочная для [сообщества Имладрис во ВКонтакте](https://vk.ru/studio_imladris)
и интерфейс автора для управления каталогом.

Код приложения находится в [vk_jewelry_bot](vk_jewelry_bot/README.md).

- [Установка бота и админки на Debian 12](vk_jewelry_bot/deploy/README.md)
- [Работа с каталогом в админке](vk_jewelry_bot/jewelry_editor/README.md)
- [Запуск админки на Windows через SSH-туннель](vk_jewelry_bot/jewelry_editor/windows/README.md)
- [Архитектура и ограничения](vk_jewelry_bot/docs/ARCHITECTURE_STATUS.md)

В репозитории находятся рабочий каталог, модели с лицензионными уведомлениями,
синтетические референсы, тесты и инструменты развёртывания. Секреты, пользовательские
фотографии, базы согласий и сессий, SSH-ключи, исходная коллекция и временные
результаты разработки в репозиторий не входят.

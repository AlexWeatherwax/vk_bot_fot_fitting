# Примерочная украшений в VK

Бот принимает название украшения и фотографию, определяет ориентиры лица,
плеч или кисти через MediaPipe и накладывает подготовленное изображение украшения.
Готовый результат отправляется в тот же диалог VK.

VK-бота. Для работы с каталогом бота используйте редактор украшений.

## Быстрый запуск

Из корня репозитория:

```bash
cd vk_jewelry_bot
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `VK_TOKEN` и `VK_GROUP_ID` в `.env`, затем:

```bash
python run.py
```

Напишите сообществу «начать», затем «каталог», выберите название украшения
и отправьте фотографию по подсказке бота. Команда «отмена» завершает ожидание фото.

Галерея и три модели MediaPipe уже включены в проект. Пересобирать каталог,
запускать импорт или генерировать демонстрационные украшения для первого
запуска не требуется. Бот работает через Long Poll; отдельный HTTP-сервер
для приёма сообщений ему не нужен.

Подробности установки, системные библиотеки Linux, Docker, systemd и
проверки — в [инструкции бота](vk_jewelry_bot/README.md).

## Как добавлять и обновлять украшения

- Готовое прозрачное изображение и посадка на фото:
  [редактор украшений](vk_jewelry_bot/jewelry_editor/README.md).
- Исходные фотографии, удаление фона и массовая подготовка:
  [импорт каталога](vk_jewelry_bot/scripts/catalog_import/README.md).
- Формат записи и параметры разных категорий:
  [описание галереи](vk_jewelry_bot/bot/jewelry/gallery/README.md).
- Требования к новым техническим фотографиям:
  [памятка по съёмке](vk_jewelry_bot/scripts/catalog_import/СЪЁМКА.md).

Рабочая галерея — `vk_jewelry_bot/bot/jewelry/gallery/`, а её
`manifest.json` хранит актуальные настройки примерки.
Сохранения редактора подхватываются ботом при следующем поиске,
показе списка или получении фотографии.

Временные результаты подготовки создаются в
`vk_jewelry_bot/scripts/catalog_import/work/` и исключены из Git.
Исходные фото и ручные настройки сохранены отдельно. Повторная сборка
галереи меняет параметры товаров; порядок работы описан в инструкции импорта.
